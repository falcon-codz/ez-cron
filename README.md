
# ez-cron

EZ Cron is a all-in-one tool to manage all your Go Cron jobs.




## Key Features

- Run all your cron jobs in seperate goroutines without hassle
- Stop, Pause, Restart, Monitor, Export Metrics for all your cron jobs easily
- Tag each cron jobs and manage cron jobs with Tag
- Use optimized pre-defined intervals or custom intervals
- Run cron jobs for 'N' number of times or until custom trigger. 
- Export Metrics on predefined interval, custom interval, or on-demand. Metrics can be exported tag based :)
